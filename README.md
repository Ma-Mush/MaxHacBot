## 🌟 О проекте

**OmniMetrics Hub** — это готовая к промышленной эксплуатации (production-ready) self-hosted платформа бизнес-аналитики для предпринимателей, селлеров маркетплейсов и команд разработки. 

Платформа объединяет разрозненные данные из **Wildberries**, **Ozon**, **Яндекс.Маркета**, **СберМаркета (Купера)**, систем учета, файлов **CSV/Excel** и произвольных сервисов через универсальный **REST API**, автоматически формируя профессиональные управленческие отчеты:
- 📄 **Исполнительские PDF-отчеты** полиграфического качества с графиками и KPI (WeasyPrint).
- 📊 **Корпоративные книги Excel (.xlsx)** с формулами, цветовыми стилями и вкладками (openpyxl).
- 🖼️ **Мобильные инфографические карточки (PNG)** для моментального просмотра на экране смартфона.
- 📑 **Синхронизацию с Google Таблицами** в режиме реального времени.
- 🧠 **Умную аналитическую сводку** из 4 ключевых тезисов (Главный рост, Точка внимания, Паттерн/Аномалия, Рекомендация).

Взаимодействие с пользователем происходит через интерактивных ботов в мессенджере **MAX** (`@t115_hakaton_max_bot`) и **Telegram** с инлайн-кнопками, календарем периодов и панелью управления аналитикой.

## ⚡ Ключевые возможности

### 1. Интеграции с ведущими маркетплейсами
- **Wildberries**: автоматическая загрузка заказов, выкупов, возвратов и географии складов по Statistics API.
- **Ozon**: получение отправлений, выплат, отмен и аналитики кластеров по Ozon Seller API.
- **Яндекс.Маркет**: синхронизация заказов, статусов и комиссий по Partner API.
- **СберМаркет (Купер)**: интеграция с Merchant API (GMV, распределение по городам и торговым точкам).
- **Песочница / Mock-режим**: если API-ключи маркетплейсов не заданы, система автоматически генерирует реалистичные данные для тестирования и презентаций.

### 2. Ручной импорт данных (CSV и Excel)
- Загрузка исторических таблиц продаж и финансовых данных селлера через CLI:
  ```bash
  python cli.py import-csv my_sales.csv --mapping wb
  ```
- Автоматический маппинг колонок (дата, выручка, число заказов, возвраты, регионы).

### 3. Движок аналитики и панель управления нейросетями (AI Control Panel)
Уникальная особенность проекта — **полный контроль над аналитическим движком** прямо из диалога в боте или через консоль:
1. **⚡ Встроенный алгоритмический анализатор**:
   - Работает на 100% локально, моментально (0 секунд задержки), без интернета и внешних зависимостей.
   - Математически рассчитывает дельты, средний чек, долю возвратов, темпы роста и аномалии каналов.
   - Формирует ровно 4 структурированных пункта на русском языке с эмодзи:
     - 🚀 **Главный рост** (наибольший прирост метрики).
     - ⚠️ **Точка внимания** (просадка, риск или узкое место).
     - 🔍 **Паттерн / Аномалия** (закономерность, конверсия или сезонность).
     - 🎯 **Рекомендация** (прикладное действие для управленца).
2. **🌐 Облачные нейросети через API-ключ**:
   - Поддержка передовых LLM: **OpenAI** (`gpt-4o-mini`), **DeepSeek API** (`deepseek-chat`), **GigaChat от Сбербанка**, **Groq** (`llama-3.3-70b`), **Anthropic** (`claude-3-5-sonnet`).
   - Ввод и смена API-ключа прямо в чате бота (с удалением сообщения ключа ради безопасности).
3. **💻 Локальная нейросеть (Ollama)**:
   - Полная конфиденциальность коммерческой тайны бизнеса: данные не покидают сервер.
   - Поддержка моделей `llama3`, `mistral`, `qwen2.5`, `phi3` через локальный сервер Ollama (`http://localhost:11434`).
   - Кнопка интерактивной проверки связи с сервером Ollama прямо в боте.
4. **🛑 Возможность полного отключения нейроаналитики**:
   - Кнопка **«🛑 Отключить нейроаналитику (Встроенный анализатор)»** в меню бота и команда `python cli.py disable-ai`.
   - При выключенной нейросети в отчетах честно отображается заголовок `⚡ Сводка встроенного анализатора:`.
   - **Защита от сбоев (Graceful Fallback)**: если внешний API недоступен или не указан ключ, отчет не падает с ошибкой, а автоматически формируется встроенным анализатором.

### 4. Нативный бот для MAX Messenger
- Разработан специально под платформу **MAX Messenger** (`platform-api2.max.ru`).
- Поддержка нативной разметки Markdown (`"format": "markdown"`).
- Удобное главное меню, инлайн-клавиатуры выбора периода (*Сегодня*, *Вчера*, *7 дней*, *30 дней*, *Текущий месяц*).
- Выбор формата доставки: экспресс-карточка, PDF, Excel или всё сразу.
- Меню синхронизации маркетплейсов с мгновенным обновлением телеметрии.

### 5. Мультиформатный экспорт
- **PDF-отчеты**: верстка на HTML5/CSS3 с разрывами страниц, нумерацией, KPI-карточками и векторными диаграммами (WeasyPrint).
- **Excel-книги (.xlsx)**: автоширина колонок, зебра-стилизация строк, форматирование валюты (`₽#,##0.00`) и процентов, встроенные превью-графики.
- **Инфографические PNG-карточки**: автопостроение графиков тренда, долей каналов (Donut Chart) и распределения по регионам.

## 🚀 Быстрый старт

### Вариант 1: Запуск через Docker Compose (Рекомендуется)

Запуск всего стека (PostgreSQL + FastAPI + MAX Messenger Bot + Telegram Bot) одной командой:

```bash
# 1. Клонирование репозитория
git clone https://github.com/Ma-Mush/MaxHacBot.git
cd MaxHacBot

# 2. Настройка переменных окружения
cp .env.example .env
```

Отредактируйте файл `.env`:
```env
# Токен бота MAX Messenger
MAX_BOT_TOKEN="ваш_токен_max_бота"

# Ключ доступа к REST API
APP_API_KEY="omni_secret_token"

# (Опционально) Telegram Bot
TELEGRAM_BOT_TOKEN="ваш_токен_telegram_бота"
ALLOWED_TELEGRAM_USERS="123456789"
```

Запустите контейнеры:
```bash
docker compose up -d --build
```

- Swagger UI документация API: `http://localhost:8000/docs`
- Проверка здоровья сервиса: `http://localhost:8000/api/v1/health`


## 💻 Справочник консольных команд (CLI)

Управление системой, тестирование отчетов и настройка аналитики производятся через утилиту `cli.py`:

| Команда | Описание |
|---|---|
| `python cli.py run-all` | Запустить API-сервер и бота MAX Messenger одновременно |
| `python cli.py run-max-bot` | Запустить только бота MAX Messenger |
| `python cli.py seed-demo [--days 60]` | Заполнить базу 60 днями реалистичной телеметрии продаж |
| `python cli.py sync-wb [--days 14] [--mock]` | Синхронизировать продажи и возвраты Wildberries |
| `python cli.py sync-ozon [--days 14] [--mock]` | Синхронизировать заказы и финансы Ozon |
| `python cli.py sync-yandex [--days 14] [--mock]` | Синхронизировать данные Яндекс.Маркета |
| `python cli.py sync-sbermarket [--days 14] [--mock]` | Синхронизировать продажи СберМаркета / Купера |
| `python cli.py test-report ecommerce_summary` | Сгенерировать PDF, Excel и PNG локально в папку `./output/` |
| `python cli.py list-reports` | Показать список всех зарегистрированных плагинов отчетов |
| `python cli.py create-plugin <name>` | Создать каркас нового отчета в `app/custom_reports/` |
| `python cli.py ai-status` | Показать текущий режим аналитики, активную модель и статус Ollama |
| `python cli.py set-ai [--mode heuristic\|api\|local]` | Настроить движок аналитики (провайдер, ключ, модель) |
| `python cli.py disable-ai` | Моментально отключить нейроаналитику (только встроенный анализатор) |

## 📡 Универсальный REST Ingestion API

Сервис предоставляет быстрый асинхронный REST API для приема любых числовых метрик. Все запросы защищены заголовком `X-API-Key`.

### 1. Отправка единичной метрики

```bash
curl -X POST "http://localhost:8000/api/v1/metrics" \
  -H "X-API-Key: omni_secret_token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "revenue",
    "value": 45900.00,
    "unit": "RUB",
    "tags": {
      "channel": "wildberries",
      "region": "Москва и МО",
      "warehouse": "Коледино"
    }
  }'
```

### 2. Пакетная загрузка метрик (до 5 000 записей за запрос)

```bash
curl -X POST "http://localhost:8000/api/v1/metrics/batch" \
  -H "X-API-Key: omni_secret_token" \
  -H "Content-Type: application/json" \
  -d '{
    "metrics": [
      {
        "name": "revenue",
        "value": 125000.0,
        "unit": "RUB",
        "tags": {"source": "ozon", "cluster": "Санкт-Петербург"}
      },
      {
        "name": "orders_count",
        "value": 68,
        "unit": "pcs",
        "tags": {"source": "ozon", "cluster": "Санкт-Петербург"}
      }
    ]
  }'
```

### 3. Прямое скачивание сгенерированного отчета через API

```bash
# Скачать исполнительский PDF-отчет
curl -X GET "http://localhost:8000/api/v1/reports/ecommerce_summary/download?format=pdf&date_range=last_7_days" \
  -H "X-API-Key: omni_secret_token" \
  -o weekly_report.pdf

# Скачать форматированную книгу Excel
curl -X GET "http://localhost:8000/api/v1/reports/ecommerce_summary/download?format=excel&date_range=last_7_days" \
  -H "X-API-Key: omni_secret_token" \
  -o weekly_report.xlsx
```

## 🧩 Архитектура расширения отчетов (Report Plugins)

Архитектура построена на паттерне **Стратегия (Strategy)**: добавление нового типа отчета не требует изменения ядра системы или таблиц базы данных.

1. Создайте каркас отчета командой:
   ```bash
   python cli.py create-plugin marketing_roi
   ```
2. Реализуйте методы в файле `app/custom_reports/marketing_roi_report.py`:
   - `fetch_data()`: выборка и агрегация метрик из базы.
   - `render_charts()`: построение диаграмм.
   - `generate_pdf()`: генерация PDF на базе шаблона Jinja2.
   - `generate_excel()`: создание файла `.xlsx`.
   - `format_telegram_caption()`: текст текстовой карточки.
3. Отчет автоматически появится в меню ботов MAX и Telegram при следующем запуске!
